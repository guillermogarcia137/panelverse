Activar el progreso automático para esta web

Para detectar las páginas dentro de otra web necesitas instalar el puente en tu navegador una vez por web.

  1. En ordenador: utiliza un gestor como Tampermonkey ↗. En iPad/iPhone: Userscripts para Safari ↗.
  2. Descarga o copia el script, añádelo al gestor y permite su ejecución en , también dentro de marcos.
  3. Vuelve aquí y pulsa Recargar. Cuando aparezca «Puente conectado», PanelVerse podrá guardar la posición.

El puente solo comunica página visible, capítulo y enlaces. No accede a tus credenciales de PanelVerse ni copia cómics. Si la web bloquea el contenedor, prueba Pestaña conectada. Los lectores no reconocidos o las webs que aíslen también las pestañas necesitan otra integración.

Bienvenido a PanelVerse

Tu estantería para organizar series y leer tus cómics. En Lector puedes importar CBR/CBZ o conectar una carpeta de Google Drive.

  1. Añade una serie de tipo Web o Archivos CBR/CBZ. Las series de archivos pueden agrupar varios números sin necesitar un enlace externo.
  2. Abre «Continuar leyendo» para entrar en el contenedor. Instala el puente si quieres detectar páginas automáticamente.
  3. Con un puente compatible, el enlace y el progreso se guardan al leer. Sin puente, puedes usar «+1 leído» y editar el último número manualmente.
  4. Inicia sesión con la misma cuenta en tus dispositivos para sincronizar tu biblioteca.
  5. Usa «Copiar biblioteca sin cuenta» para llevar tus series anteriores a la cuenta. Conserva también copias JSON.
