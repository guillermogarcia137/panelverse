Los datos se guardan en este navegador. Exporta una copia antes de cambiar de dispositivo o borrar sus datos.

Importar una copia

Las series con el mismo identificador se actualizarán. Las demás se añadirán. Antes de importar se descarga una copia de tu biblioteca actual.

Bienvenido a PanelVerse

Tu estantería para organizar las historias que lees online.

  1. Añade una serie con su enlace y, si quieres, una portada.
  2. Abre «Continuar leyendo» para visitar la página guardada.
  3. Al volver, pulsa «+1 leído» o edita el último número leído.
  4. Exporta una copia para conservar tu biblioteca.

El ejemplo de Superman empieza en cero: no representa tu progreso real. El enlace apunta al #35 como referencia.

Esta versión no sincroniza dispositivos ni descarga cómics. La biblioteca funciona sin conexión después de la primera visita; los enlaces y portadas externas necesitan Internet.

En iPad, una vez publicada con HTTPS: Safari → Compartir → Añadir a pantalla de inicio.
